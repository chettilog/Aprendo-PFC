# Política de Privacidade - Aprendo

**Versão 1.0**

## 1. Controlador dos dados

A Aprendo Tecnologia Educacional Ltda. é a controladora dos dados pessoais tratados nesta plataforma.

## 2. Dados coletados

Coletamos os seguintes dados no cadastro:
- Nome
- E-mail
- Senha (armazenada com hash criptográfico via bcrypt)

Durante o uso da plataforma, também registramos:
- Data e hora de acessos
- Endereço IP
- Ações realizadas (logs de auditoria)
- Data e versão do aceite dos termos

## 3. Finalidades

Os dados coletados são utilizados exclusivamente para:
- Autenticação e identificação do usuário na plataforma
- Auditoria de segurança e prevenção de fraudes
- Cumprimento das obrigações previstas nos Termos de Uso

## 4. Base legal (LGPD)

O tratamento dos dados é realizado com base em:
- Execução de contrato (Art. 7º, V da LGPD) para autenticação e uso do serviço
- Legítimo interesse (Art. 7º, IX da LGPD) para logs de segurança

## 5. Compartilhamento

Não compartilhamos dados pessoais com terceiros, exceto quando exigido por lei.

## 6. Direitos do titular

O usuário pode a qualquer momento:
- Solicitar acesso aos seus dados
- Corrigir informações incorretas
- Solicitar a exclusão da sua conta

## 7. Segurança

Adotamos medidas técnicas de segurança, incluindo criptografia de senhas, autenticação via tokens JWT e registro de acessos para auditoria.

## 8. Contato

Para exercer seus direitos ou tirar dúvidas: privacidade@aprendo.com.br
